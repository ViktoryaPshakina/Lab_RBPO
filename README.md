# Ветеринарная клиника

Система учёта приёмов, лечения и истории болезней.

## Сущности
- **Владелец**: имя, фамилия, телефон (уникальный), email (уникальный)
- **Питомец**: имя, вид, возраст, владелец
- **Врач**: имя, фамилия, специализация, телефон (уникальный)
- **Приём**: дата/время, причина, жалобы, статус, питомец, врач
- **Лечение**: назначения, препараты, дата контрольного визита

## Бизнес-операции
1. Регистрация владельца с питомцем
2. История болезни питомца
3. Расписание врача
4. Удаление владельца с каскадом
5. Отчёт по активным приёмам

## БД
PostgreSQL с ограничениями:
- UNIQUE: `owners.phone`, `owners.email`, `vets.phone`
- CHECK: `status IN ('SCHEDULED', 'IN_PROGRESS', 'COMPLETED', 'CANCELLED')`
- ON DELETE CASCADE для целостности
