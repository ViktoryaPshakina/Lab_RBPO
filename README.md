## Лабораторная работа №6: Настройка HTTPS и PKI

В рамках данной работы реализована инфраструктура открытых ключей (PKI) и настроен протокол HTTPS.

### 1. Цепочка доверия (Certificate Chain)
Создана трехзвенная цепочка сертификатов:
1. **Root CA:** Самоподписанный корневой сертификат организации.
    - Алиас: `rootCA_23271`
    - CN: `RootCA-1БИБ23271`
2. **Intermediate CA:** Промежуточный центр сертификации, подписанный корнем.
    - Алиас: `intCA_23271`
    - CN: `IntermediateCA-1БИБ23271`
3. **Server Certificate:** Конечный сертификат сервера `localhost`.
    - Алиас: `server_23271`
    - CN: `localhost`
    - SAN: `dns:localhost`

### 2. Настройка TLS в Spring Boot
Сервис переведен на работу по порту **8443** с использованием протокола TLS.
Для хранения ключей используется формат **JKS** (`studentServer.jks`).

### 3. CI/CD Процесс
Настроен пайплайн в GitHub Actions, выполняющий:
- Компиляцию проекта.
- Выполнение тестов.
- Упаковку в JAR.
- Загрузку артефакта сборки.
  Пароль от хранилища ключей скрыт в GitHub Secrets (`SSL_STORE_PASSWORD`).
